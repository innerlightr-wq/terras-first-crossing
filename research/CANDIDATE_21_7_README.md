# First-crossing descent for the complete 21/7 family

Research certificate for independent review. It builds on the family reported at commit 925b755. The claim concerns one shell. For every integer n ≥ 2 realizing an entire word in this family, the orbit falls below n at the first time the coefficient falls below one. That time can precede the final step. The continuation supplies information about n, so the quantifier over full-word realizers is essential.

## Reproduce

A C++20 compiler with 128-bit integer support and Python 3.8 or newer suffice. OpenMP is optional. Allow roughly 1 GB or more of free memory for the span calculation, depending on the thread count and allocator. Run with assertions enabled.

```sh
g++ -O3 -std=c++20 -fopenmp span.cpp -o span
OMP_NUM_THREADS=2 ./span
python3 prefix.py
```

The first command chain computes 1,372,257,936 distinct residues and a minimum cyclic 163-point span of 3,611,678,508. The Python checker consumes that exact span, enumerates the alphabet and marker junctions, encloses logarithms using rational arithmetic, and checks the seed inequalities. The files can also be audited individually.

## Family and crossing

Use the one-bit Collatz map T, with T(x)=x/2 for even x and T(x)=(3x+1)/2 for odd x. Write a(t) for the number of odd steps in the first t steps, ρ_t=3^{a(t)}/2^t, and x_t=ρ_t(n+M_t). Each odd step at time t adds 1/(3ρ_t) to M. The word starts with 11111110 and ends with 111100000. At each intervening byte boundary t prescribe a(t)=floor(tD/K)+2, with K=1412737287532845639425 and D=891337988684307508298. Allow every eight-bit word ending in zero with the prescribed weight of five or six. There are 21 and seven choices, respectively.

Put Λ=K ln 2−D ln 3>0 and η=8D/K−5. At a middle boundary, exactly,

    ρ_t = 3^(2−{tD/K}) exp(−tΛ/K).

Thus all such boundaries have ρ_t>2.999. Immediately before a six-one byte, {tD/K}≥1−η and ρ_t≤3^(1+η)<256/81. The difference between those bounds is less than 0.162. The only middle-byte location where the coefficient can first drop below one is two steps into 00111110. That letter has weight five. The exact safety condition is {tD/K} + tΛ/(K ln 3) ≤ 2−log₃4. The checker handles these phases through integer indices and certified logarithms.

## All full-word seeds are large

The middle schedule has 8,377,183,976,278,983,657 six-one bytes. Since 20η<1, any twenty consecutive middle bytes contain at most one six. Ignore up to 19 edge starts. At every remaining six-one start, seven preceding bytes and twelve following bytes all have weight five. There are at most 7·21^12 different forward windows of 104 bits, so at least 163 starts share a window. For integers realizing a given word these are 163 distinct states. Otherwise determinism repeats the unique terminal marker 0111100000 at an earlier position. The Python checker verifies marker uniqueness throughout every possible junction and all selected starts precede the marker.

For a byte b, write C(b)=Σ 2^i 3^(number of ones after i), summed over its one-bits with zero-based indexing. For seven incoming five-one bytes b₀,…,b₆, concatenate their affine maps. Their incoming ancestor is multiplied by 3^35 and disappears modulo 3^35. The common forward window fixes the same integer representative r modulo 2^104. Thus z=(x−r)/2^104 for the selected states lies in a common translate of the residue set generated by

    2^(−160) Σ_(i=0)^6 256^i 243^(6−i) C(b_i)   modulo 3^35.

If any two distinct integers z occupy the same residue, their span is at least 3^35. Otherwise the minimum cyclic span of 163 residues supplies a lower bound, translation-invariant even across zero. The C++ computation groups by residue interval, checks spans within and between adjacent intervals and includes the cyclic end-to-start boundary. Each interval contains at least 163 elements.

Each completed byte contributes C(b)/(3^weight·ρ_start) to memory. Direct enumeration bounds it by weight/3 on this shell even if there is an interior crossing. The head and tail also satisfy this bound for their total contributions. Nonnegativity gives M_t≤M_K≤D/3. The anchor states lie between 2.999n and (256/81)(n+D/3). Writing σ=3,611,678,508 gives

    2^104 σ < 0.162 n + (256/81) D/3.

Every integer realizing a full word therefore satisfies n>4.5218×10^41. This reasoning uses neither endpoint failure nor minimality among counterexamples. In particular nΛ>D/3, which settles descent if the first crossing occurs at K.

## Earlier first crossings

If an earlier first crossing at j fails, E=j ln 2−a(j) ln 3 is positive and nE<n(exp(E)−1)≤M_j. Since every odd step before the first crossing starts at coefficient ≥1, M_j≤a(j)/3. There are only two zero steps from the start t=j−2 of the exceptional byte, so a(j)=floor(tD/K)+2 there. Set h=K a(j)−Dj. Then K E=jΛ−h ln 3. The new seed floor and M_j≤D/3 imply −1<h<131, and j≡−h D^(−1) mod K determines j uniquely in [0,K). Exact comparisons in prefix.py leave only h=60 and j=651838711708843936730 after the coarse test nE<a(j)/3.

Before an actual first crossing any previous appearance of 00111110 must have begun at ρ≥4. Its contribution is ≤(844/243)/4<0.94. A regular five-one byte has contribution <(682/243)/2.999<0.94, and a six-one byte contributes <(1330/729)/2.999<0.94. The head contributes less than 7/3. Thus

    M_j < 7/3 + 0.94 (j−10)/8.

At the sole remaining index this gives M_j/E<4.3026×10^41, strictly below the seed floor. This closes the earlier first-crossing case on the stated shell.
